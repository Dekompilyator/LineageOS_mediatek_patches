# LineageOS 14.1 common patches for old MediaTek MT67xx devices

# Usage instructions
```
# Edit path in scripts for your device manually
git clone https://github.com/Dekompilyator/LineageOS_mediatek_patches.git /lineage-source-dir/device/manufacturer/codename/patches

# Apply patches
source device/manufacturer/codename/patches/apply-patches.sh

# Reverse patches
source device/manufacturer/codename/patches/apply-patches.sh
```
